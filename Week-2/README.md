# Week 2 – Data Collection, Cleaning and Preprocessing

This week focuses on data collection, cleaning, and preprocessing for the Delhivery logistics case study.

## Objectives

- Collect logistics-related public data
- Understand dataset characteristics
- Identify missing values
- Detect duplicate records
- Correct data types
- Identify and handle outliers
- Normalize and standardize numerical features
- Prepare data for further analysis and machine learning

## Case Study

Delhivery Limited – Indian E-Commerce Logistics

## Dataset

A publicly available E-Commerce Shipping Data dataset is used as a reference/proxy dataset for this academic case study.

> Note: Delhivery's confidential or internal operational data is not used.
